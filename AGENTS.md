# SVN prototype

This repository prototypes **SVN**, a UI stack built around modern browser APIs instead of a complex frontend framework.

- Use **Hono** as the small server and routing layer. Return HTML from endpoints with **Hono JSX**.
- Use **Web Awesome** for UI components.
- Build a multi-page application, then enhance it with native browser APIs to make navigation and interaction feel as seamless as a single-page application where practical.
- Use **npm** to manage the project. Keep prototyping tooling minimal: no formatter, linter, or test runner.

For web UI design or implementation, read and apply `.agents/skills/svn-web-ui/SKILL.md`.

Keep this file focused on the stack and its philosophy. SVN's implementation details live in the dedicated skill.
